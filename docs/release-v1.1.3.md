# SonoTune v1.1.3

This update gives more space to your tracks and fixes the playback wave on wide windows.

## Changes

- **A continuous playback wave.** The wave reaches the seek thumb at any window width, without gaps or seams between repeated fragments.
- **A more compact library.** Sorting and list/grid controls now sit in the top bar beside search. Their separate desktop row and the library status footer are removed.
- **A slimmer player.** Desktop height is reduced from 112 to 100 px while keeping control sizes, internal spacing, and columns. The seek bar has more space below the playback buttons.
- **Pin from where you listen.** Pin the current song from the bottom player or any of the three Home highlight cards. Add an optional caption, or edit an existing pin.
- **Source folders in track menus.** Right-click a track or use its three-dot button to see and copy its folder path.
- **Capsule navigation restored.** The experimental sidebar silhouettes are replaced with the original rounded backgrounds.
- English/Russian labels and regression coverage for the updated controls, waveform, and source-folder display.

## Download and update

Download **SonoTune-Windows.zip**, extract the entire archive, and run **SonoTune.exe**.
Keep the accompanying DLLs and folders beside it. Windows x64 and Microsoft Edge
WebView2 Runtime are required.

Before updating, choose **Quit SonoTune** from the tray menu to fully close the old
version. Your library and preferences are retained. Keep the portable app in a stable
folder; if you move it, update startup and “Open with” registration from Settings.

The release includes the portable player, source archive, MIT license, build information,
and SHA-256 checksums. Third-party license notices and offline fonts are bundled.
