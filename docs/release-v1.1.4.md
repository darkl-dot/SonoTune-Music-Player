# SonoTune v1.1.4

This update lets you select several tracks and act on all of them at once.

## Changes

- **Select a group.** Alt+click tracks in the list or grid, or choose Select in a track's context menu. Checkboxes appear while selection is active.
- **Actions for the whole selection.** Play starts with the first selected track and queues the rest in view order. Queue, add to a playlist, favorite, edit tags, pin, remove from a playlist, and remove from the library apply to every selected track.
- **A selection bar.** It shows how many tracks are selected and offers Select all and Clear selection. Alt+A selects every visible track, and Escape leaves selection.
- **Editors open in sequence.** Tag and pin dialogs run one track after another without dropping the rest of the selection.
- **Scoped to the current view.** Selection resets when you change the section or grouping, so actions never reach hidden tracks.
- English/Russian labels and regression coverage for selection, keyboard control, and multi-track playlist actions.

## Download and update

Download **SonoTune-Windows.zip**, extract the entire archive, and run **SonoTune.exe**.
Keep the accompanying DLLs and folders beside it. Windows x64 and Microsoft Edge
WebView2 Runtime are required.

Before updating, choose **Quit SonoTune** from the tray menu to fully close the old
version. Your library and preferences are retained. Keep the portable app in a stable
folder; if you move it, update startup and “Open with” registration from Settings.

The release includes the portable player, source archive, MIT license, build information,
and SHA-256 checksums. Third-party license notices and offline fonts are bundled.
